# 🚕 Rapido Bangalore Rides Analysis

An interactive data analytics dashboard for analyzing Rapido ride data in Bangalore using Python, Pandas, Plotly, and Streamlit.

## 📊 Project Overview

This project analyzes Rapido ride data from Bangalore to identify important patterns and trends in rides, revenue, distance, and other key metrics.

The project provides an interactive dashboard built using Streamlit and Plotly.

## ✨ Features

- 📈 Ride trend analysis
- 💰 Revenue analysis
- 🚕 Ride and booking analysis
- 📊 Interactive Plotly visualizations
- 🔮 Revenue forecasting
- 📅 Date-wise analysis
- 🎛️ Interactive Streamlit dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Statsmodels
- Prophet
