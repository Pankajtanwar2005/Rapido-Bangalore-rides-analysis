# Rapido-Bangalore-rides-analysis

\# 🚕 Rapido Bangalore Rides Analysis



A data analytics and interactive dashboard project for analyzing Rapido ride data in Bangalore using Python, Pandas, Plotly, Streamlit, and time-series forecasting.



\## 📌 Project Overview



This project analyzes Bangalore Rapido ride data to identify important patterns and trends in ride bookings, cancellations, revenue, customer behavior, and ride demand.



An interactive Streamlit dashboard has been developed to visualize the analysis through charts, KPIs, filters, and forecasting.



\## 🎯 Objectives



\- Analyze Rapido ride-booking trends

\- Understand ride demand over time

\- Analyze completed and cancelled rides

\- Study revenue-related patterns

\- Identify important ride and customer trends

\- Visualize data using interactive charts

\- Apply time-series forecasting for future ride demand



\## 🛠️ Technologies Used

\- Streamlit

\- Plotly

\- Statsmodels

\- Prophet

\- Matplotlib
